## Generated in code (no external file)

- Muzzle flash, impact decals, tracers, explosion flash: procedural canvas/Three.js geometry generated at runtime.
- All SFX (shots, reload, impacts, charge beeps, explosion): synthesised at runtime with the WebAudio API, no samples.
- Soldier gear (helmet + NVG mount, ear-pro, plate carrier + pouches, belt, backpack, knee pads, boots, glasses/balaclava variants): procedural geometry skinned to the Quaternius skeleton in `client/src/render/soldier.ts`.
- Faction camouflage (multicam "Assalto" / urban grey "Difesa"): procedural shader noise (`clothMaterial`) — no texture file.
- Rifle red-dot optic (tube, hood, lens, dot), first-person gloves and sleeves, magazine reload animation, death ragdoll (Rapier capsules): procedural, in `client/src/render/viewmodel.ts` / `ragdoll.ts`.
- Stage 1 blockout soldier/rifle proxies: removed.
- Map "Banchina Est": blockout geometry built from boxes in `shared/src/map/portoArdesia.ts` + the textures above.
- No Wolfenstein: Enemy Territory asset, name, sound or trademark is used; the GPLv3 ET source is a mechanics reference only (`docs/et-reference.md`).

Keep original source files in `media/source/` where appropriate; originals for this stage were downloaded to a scratch folder and are verifiable by the hashes above. Tools used only in the production pipeline are distinct from assets shipped in the APK. Code dependencies (adapted code: Claude-of-Duty spring, MIT, see Weapon source review; three MIT, @dimforge/rapier3d-compat Apache-2.0; offline pipeline only: @gltf-transform MIT, meshoptimizer MIT, sharp Apache-2.0 — not shipped) are tracked via `package-lock.json`, not in this table.
